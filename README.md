# 球球大冒險

忍者貓球球的橫向捲軸動作遊戲：一路跑、跳、揮爪、丟忍具，救出被抓走的夥伴，打倒三大關的魔王。
用瀏覽器就能玩，電腦和手機都可以。

**線上玩**：https://yayaxcharles.github.io/qiuqiu-adventure/

## 操作

### 鍵盤

| 按鍵 | 動作 |
|---|---|
| ← →（或 A D） | 移動；按住 Shift 是慢慢走 |
| ↑（或 W） | 按住朝上丟 |
| ↓（或 S） | 蹲下；在空中按住是朝下丟 |
| 空白鍵 | 跳（按越久跳越高；空中再按二段跳） |
| J | 普通攻擊：貼近敵人自動揮爪，遠一點丟手裏劍 |
| K | 特殊攻擊：救村貓拿到的忍具（有彈數，連發的按住一直丟） |
| L | 大招：爆裂符、焙烙玉、煙玉 |
| Q | 換大招 |
| I | 地上翻滾／空中衝刺 |
| Enter | 開始／接關 |
| P 或 Esc | 暫停（暫停畫面有完整按鍵表） |
| M | 靜音切換 |

標題畫面按 ← → 或數字鍵選第幾關，按 R 進動作練習場。

### 手機

橫著拿，用畫面上的觸控按鈕操作：左邊方向盤；右邊「跳」「攻」（普通攻擊）「特」（特殊攻擊）「大」（大招）「換」（換大招）。
第一次要點一下畫面，瀏覽器才會放出聲音。

### 網址參數

- `?stage=2`：直接開第二關（1～3）
- `?stage=practice`：動作練習場

## 在自己電腦上跑

需要 Node.js 24。

```sh
npm install        # 第一次先裝套件
npm run dev        # 開本機伺服器，瀏覽器打開它印出來的網址
npm test           # 跑測試
npm run build      # 打包到 dist/
```

Windows 也可以直接點兩下 `play.cmd`，會自動裝套件並開在 http://localhost:5393/ 。

## 上線

在 Git Bash 跑 `sh tools/deploy.sh`：先在要推的那一筆提交上測試並打包，推原始碼到 main，
把打包結果推到 gh-pages 分支，等網站建好、確認線上換成這一版才算完成。細節寫在腳本檔頭。
