# 球球橫向動作：動作清單與規劃（2026-09-26，使用者出門兩天，交代「自己思考、規劃跟製作」）

## 定位
越南大戰（Metal Slug）那一類橫向捲軸：一直往右推進、近戰加遠程、跳躍閃躲。球球是忍者貓：近戰＝揮爪，遠程＝手裏劍，閃避＝翻滾。
使用者 09-25 的原則照舊：**先把動作做順，才做關卡**。這兩天的目標是「動作庫＋一個能操作的動作測試場」，不做關卡、不做敵人 AI。

## 做法（09-26 驗證可行）
- Google Vids「動畫」分頁（Gemini Omni，免費）：上傳一張綠底球球，描述動作，4 秒、720p。
- 在使用者的 Chrome 裡操作；生好的片段直接從側邊欄的預覽影片抓下來（不用插入時間軸、不用匯出）。
- `vids/process_action.py`：丟白畫面與重複格 → 找出動作段 → 去綠底、清 Gemini 浮水印、壓綠 → 對齊 → 單格圖＋預覽動畫＋總覽表。
- 每個動作生 1～3 次，挑最像球球、方向一直朝右、動作乾淨的那支。

## 忍者版的「武器系統」（使用者 09-26：越南大戰是槍、而且很多種槍跟型態，我們主軸是忍者）
越南大戰的骨架是「無限的基本槍＋撿到的限量強力槍＋手榴彈＋坦克」，照這個骨架換成忍具與忍術：

| 越南大戰 | 忍者版 | 手感 |
|---|---|---|
| 手槍（無限） | **手裏劍**（無限） | 單發直線，可朝前、朝上、空中朝下 |
| 重機槍 H | **苦無連射** | 高速連發，按住不放 |
| 火箭 R | **風魔大手裏劍** | 大、慢、會穿透，飛出去再轉回來 |
| 火焰 F | **火遁·火龍** | 近距離噴火，燒到會持續扣血 |
| 散彈 S | **散針**（菲菲客串） | 扇形一把針，近距離很痛 |
| 雷射 L | **雷遁·紫電** | 一道持續的雷光 |
| 追蹤 C | **式神紙鶴** | 自動追敵人的紙鶴 |
| 地面爬行 I | **地走り** | 貼地跑的爆炸符 |
| 彈跳 D | **毛球彈**（本作已有） | 會彈跳的毛球 |
| 手榴彈 | **爆裂符**（拋物線）／**煙玉**（放了短暫隱身） | 副武器，有數量 |
| 大絕（原作沒有） | **分身術**（兩個分身跟著出招）／**口寄せ·巨貓**（掃全畫面） | 很少次 |
| 坦克 SV-001 | **大凧**（騎大風箏飛行關）／**口寄せ·巨蛙**（騎乘） | 載具 |

**做角色動畫的原則**：一種「出招姿勢」配很多種武器（越南大戰也是上半身共用幾個射擊姿勢），
飛出去的東西（手裏劍、火龍、雷光、紙鶴）另外做成特效圖由程式發射，**角色動畫裡不要畫飛行道具**——
影片裡畫死的手裏劍沒辦法換成火球，也對不準敵人。提示詞要寫「空手做投擲動作，道具之後由遊戲加上」。

需要的出招姿勢（每個一支影片）：
- 前投（單手快投）、上投（朝頭上）、空中下投（跳起來朝斜下）
- 蹲姿前投
- 連射（左右手交替快投，可循環）
- 雙手大投（大手裏劍）
- 結印→推掌（火遁、雷遁、式神共用；結印幾格＋推出去幾格）
- 拋投（爆裂符、煙玉：由下往上甩）
- 大絕施術（雙手結印、全身冒煙）

需要的特效（綠底另生，或 Codex 生圖由程式轉）：旋轉手裏劍、苦無、大手裏劍、火焰流、雷光、紙鶴、爆炸、煙霧、分身殘影。

## 移動類（使用者 09-26 補：走路、蹲下移動）
待機、走路、跑步（衝刺）、蹲下、蹲走（匍匐前進）、跳（起跳／空中／落地）、二段跳、衝刺、滑鏟、翻滾、受傷、倒下。

## 生成順序（第二版，照使用者 09-26 追加調整）
1. 跳躍（重生，要一直側面）2. 蹲下（重生）3. 走路 4. 蹲走 5. 衝刺 6. 空中下投（使用者點名「跳躍丟手裏劍」）
7. 前投（空手版）8. 上投 9. 連射 10. 結印推掌 11. 受傷 12. 倒下 13. 拋投 14. 雙手大投 15. 翻滾／滑鏟 16. 大絕施術
特效另排，角色動作優先。

## 提示詞共同規則（實測學到的）
- 「Tiny motion」會讓動作小到不像攻擊 → 要寫成格鬥遊戲式的大動作。
- 一定要寫「側面朝右、整段都不轉向鏡頭」（跳躍第 1 支半空轉正面）。
- 原地動作要寫「stays in the center, does not move across the frame」。
- 固定鏡頭、綠底不變、沒有地板與影子。

## 遊戲端（動作測試場）
- 沿用 `src/physics.ts`（手感七項已測）、背景、鏡頭、木樁人；把骨架球球換成「一格一格播的動作圖」。
- 狀態機：待機／跑／起跳／空中／落地／揮爪／丟手裏劍／蹲／翻滾／受傷／倒下；攻擊有「出招格」（打中判定在哪幾格）。
- 用瀏覽器實際跑、錄每格位置，量有沒有跳格、換動作時有沒有閃一下。
- 交付：`play.cmd` 雙擊開、按鍵說明、一頁動作總覽（每個動作的預覽動畫）。
