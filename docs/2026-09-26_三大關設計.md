# 球球大冒險：三大關設計（2026-09-26，使用者：「做一個越南大戰感覺的橫向捲軸遊戲」「做出三大關也要設計敵人跟魔王」「圖片跟場景一樣用 codex」）

## 核心手感（越南大戰那套，換成忍者）
- 一直往右推進；畫面只往右捲，不能回頭（越南大戰規則），角色不能走出畫面左邊。
- 一命制＋血量：被打三下倒（越南大戰是一下，我們寬一點）；三條命，用完出現「接關」。
- 基本攻擊：近身自動揮爪（敵人貼近時按攻擊＝揮爪，遠一點＝丟手裏劍，越南大戰的「近身自動用刀」）。
- 撿武器：解救被綁的村貓，村貓會丟出忍具（見武器表），限量用完退回手裏劍。
- 副武器：爆裂符（拋物線，有數量）。
- 分數、連殺、關底結算（解救幾隻、分數）。
- 動作：待機、走、跑（衝刺）、跳、空中丟、蹲、蹲走、揮爪、受傷、倒下（動作圖由 Vids 影片轉出，見動作清單）。

## 三大關（敵人與魔王沿用爪破魔塔的立繪：每隻有待機、出招、受傷、擋、倒下五張；魔王有第二階段）

### 第一關　黃昏山村 → 竹林 → 山賊寨（教學關）
- 場景：黃昏山村（屋頂、曬魚架）→ 竹林（竹子前景、落葉）→ 山賊寨（木柵、瞭望台、營火）。
- 小兵：
  - `rat` 鼠兵：成群小跑衝過來咬，一碰就倒（練手感）
  - `orange_bandit` 橘貓山賊：走過來揮木棒；被打會後退
  - `black_ninja` 黑衣忍者：站遠處丟苦無（第一個遠程敵人），會跳到屋頂上
  - `crow_small` 烏鴉：從天上俯衝（教玩家往上丟、跳）
  - `wild_boar` 野豬：從畫面右邊直線衝鋒，要跳過
- 中魔王：`drum_tanuki` 太鼓狸：敲太鼓發出地面震波（要跳）、叫小狸
- 魔王：`orange_king` 橘皮大王（兩階段）：
  - 一階：肚皮壓（跳到你頭上）、丟魚骨頭（拋物線）、滾過來（要跳過）
  - 二階（`orange_king_p2`，站起來全身是刺）：刺反彈（近戰吃傷害）、泰山壓頂（地面陰影預告）、滾更快
- 被綁村貓：3 隻（給 H、S、爆裂符）

### 第二關　妖怪祭典燈籠街 → 河童川 → 山頂神社（夜）
- 場景：夜祭（燈籠串、攤位、煙火）→ 河堤（木橋、水面）→ 神社（鳥居、石階、紅楓）。
- 小兵：
  - `lantern_ghost` 燈籠鬼：飄在半空吐火球
  - `kasa_obake` 傘妖：一跳一跳前進，落地有小震
  - `paper_crane` 紙鶴群：一整排波浪飛過來
  - `kappa` 河童：從水裡冒出來吐水彈、再潛下去
  - `mask_dancer` 面具舞者：丟扇子（會轉回來）
  - `fox_miko` 白狐巫女：在遠處放狐火（追蹤慢）
  - `tengu` 天狗：在空中用羽扇刮風，把球球往後吹
- 中魔王：`frog_daimyo` 蛙大名（兩階段，河川段）：舌頭抓人、跳起來砸水花、叫蝌蚪 `tadpole`
- 魔王：`tanuki_lord` 狸大人（兩階段，神社）：
  - 一階：變身成石像（無敵，要等）、葉子手裏劍扇形、腹鼓震波
  - 二階（`tanuki_lord_p2`）：分身三隻（只有一隻是真的）、巨大化踩踏
- 被綁村貓：4 隻（給 F、C、R、爆裂符）

### 第三關　鐵爪機關城（越南大戰味最重：機關、砲台、要塞）
- 場景：城下（石牆、齒輪、蒸汽管）→ 工廠內部（輸送帶、鍛爐）→ 天守閣頂（暴風雨）。
- 小兵：
  - `vacuum` 吸塵機器：地上來回、把手裏劍吸走
  - `mini_broom`／`broom_centipede` 掃把蜈蚣：一節一節的長身體，打斷會分裂
  - `iron_arhat` 鐵羅漢：擋在前面的重甲兵，正面擋子彈（要跳到背後或用穿透）
  - `armor_ghost` 空鎧武者：舉槍突刺
  - `plated_beetle` 甲蟲砲台：固定在牆上射擊
  - `wraith_samurai` 怨靈武士：半透明，瞬移斬
  - `guardian_statue` 守門石獅：只在門口，打爛才能過
- 中魔王：`roomba_king` 掃地機王（大型機器，像越南大戰的坦克）：吸力把人拉過去、噴垃圾彈、衝撞
- 魔王：`iron_claw` 鐵爪機關貓（兩階段）：
  - 一階：巨爪橫掃（要蹲或跳）、背後飛彈（從上面落下，有落點提示）、放出 `mini_broom`
  - 二階（`iron_claw_p2`）：裝甲剝落、雷射掃射（要跑到安全位置）、暴走衝撞
- 被綁村貓：4 隻（給 L、H、R、爆裂符）
- 通關：天守閣頂夕陽，球球跟村貓們合照（Codex 一張結局圖）

## 美術分工
- **Codex 生**：三關背景（每關 3 段 × 遠景／中景／近景地面）、武器圖示、飛行道具（手裏劍、苦無、大手裏劍、火焰、雷光、散針、紙鶴、爆裂符、爆炸、煙霧）、被綁村貓、村貓丟道具、關卡標題、結局圖。畫風照球球：粗黑描邊、平塗、偏粉奶油色系；背景一律不畫角色。
- **沿用爪破魔塔**：所有小兵與魔王的立繪（`F:\ClaudeWork\qiuqiu-coop\public\assets\monsters\`，五個姿勢），程式做擺動、閃白、震動、倒下彈飛。之後有空再用 Vids 把重點敵人動起來。
- **球球**：Vids 影片轉出來的動作圖（`public/sprites/qiuqiu/`）。

## 做的順序
1. 動作測試場（動作圖取代骨架）← 進行中
2. Codex 背景與特效（跟 1 同時做，不碰程式）
3. 關卡系統：捲軸、出怪表、被綁村貓、武器、血量命數、分數、過關與結算、標題與接關
4. 第一關完整可玩 → 第二關 → 第三關（每關做完用瀏覽器實際跑過、截圖）
5. 魔王戰：每隻魔王的招式照上面，第二階段換立繪
